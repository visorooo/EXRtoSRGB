Windows integration

Double-clicking an .exr opens it here, and .exr files get their own aperture icon. Untick to hand the file type back.

Adds a convert submenu to .exr files in Explorer, whatever app owns the file type. On Windows 11 it sits under “Show more options”.

Written per-user under HKCU — no admin rights, and nothing changes for anyone else on the machine.
